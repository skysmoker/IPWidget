# IPWidget

Лёгкий фоновый виджет для Windows, отображающий текущий внешний IP-адрес, флаг и трёхбуквенный код страны.

## Возможности
- Постоянное отображение текущего IP, флага и кода страны (ISO alpha-3) поверх окон.
- Копирование IP-адреса в буфер обмена по клику левой кнопкой мыши.
- Системные уведомления при смене IP-адреса или страны (защита при обрыве VPN).
- Настройка прозрачности, масштаба окна, угла экрана и периода опроса.
- Светлая, тёмная и системная темы оформления Windows 11.
- Автоматическое обновление, определение провайдера, отображение пинга.
- Сворачивание в системный трей и автозапуск вместе с Windows.

## Сборка .exe из исходников
pip install -r requirements.txt
pyinstaller --noconsole --onefile --icon=app.ico --name=IPWidget --collect-data pycountry main.py
