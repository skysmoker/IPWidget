# IPWidget

[English](README.md) | **Русский**

Лёгкий и минималистичный десктопный виджет для Windows на Python и PyQt6. Отображает ваш текущий внешний IP-адрес, флаг страны, город и индикатор состояния сети прямо поверх рабочего стола.

## Основные возможности

- **Внешний IP и геолокация:** Показывает публичный IPv4-адрес, флаг страны, трёхбуквенный код страны (ISO3) и город с автоматическим переключением между резервными API (`ipwho.is`, `ip-api.com`, `geojs.io`, `ipinfo.io`).
- **Подробная карточка при наведении:** Наведите курсор на виджет на 1 секунду, чтобы увидеть провайдера (ISP), активный сетевой интерфейс с локальным IP, адрес IPv6 (если доступен), задержку (пинг) и часовой пояс.
- **Приватный режим:** Скрытие IP-адреса маской (`•••.•••`) до наведения курсора.
- **Гибкое расположение и темы:** Привязка к любому углу экрана или свободное перетаскивание (`СКМ` или `Alt + ЛКМ`) с прилипанием к краям. Поддержка светлой, тёмной и системной тем Windows, настройка прозрачности и масштаба (75%–150%).
- **Экономия ресурсов (режим AFK):** Автоматически ставит опросы на паузу при простое пользователя более 5 минут и мгновенно возобновляет работу при активности, выходе из сна или разблокировке экрана.
- **Автоскрытие в полноэкранном режиме:** Прячется при запуске игр, фильмов или презентаций на весь экран.
- **Двуязычный интерфейс (RU / EN):** При первом запуске автоматически определяет язык Windows, а также позволяет мгновенно переключаться между русским и английским в настройках.
- **Встроенное автообновление:** Проверяет новые релизы на GitHub и обновляет `.exe`-файл в один клик.

## Быстрый старт

### Готовый исполняемый файл (Windows)
1. Скачайте свежий `IPWidget.exe` со страницы [релизов](https://github.com/skysmoker/IPWidget/releases/latest).
2. Запустите `IPWidget.exe` (установка не требуется).
3. **Левый клик** по виджету копирует IPv4 в буфер обмена; **правый клик** открывает настройки.

### Запуск из исходного кода
1. Клонируйте репозиторий: `git clone https://github.com/skysmoker/IPWidget.git`
2. Перейдите в папку: `cd IPWidget`
3. Создайте и активируйте виртуальное окружение: `python -m venv venv` и `venv\Scripts\activate`
4. Установите зависимости: `pip install -r requirements.txt`
5. Запустите виджет: `python main.py`
